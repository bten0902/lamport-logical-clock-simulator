Lamport Clock Rules

  1. Before every local/send event, increment the process clock.
  2. Attach the current clock value to the outgoing message.
  3. When a message is received, set C = max(C, messageTimestamp) + 1.
  4. If event A causally precedes B, then L(A) < L(B).
